# 🎹 Т9-режим для CardKB — русский набор цифрами (Orange Pi Zero 3W)

Печать русского текста на M5Stack CardKB через **Т9** (как на кнопочных телефонах):
набираешь цепочку цифр — словарь подставляет слова, стрелками выбираешь из вариантов.
Слова, которых нет в словаре, вводятся вручную (**multi-tap**) и **автоматически добавляются в словарь**.

Работает в составе `m5hub.py` (драйвер M5Stack PaHub: Joystick V2 + Scroll + CardKB) как отдельный режим.

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **Fn+Tab** | включить / выключить Т9-режим (LED джойстика мигает, внизу экрана — окошко с кандидатами) |
| **2–9** | набор букв (2=абвг, 3=деёжз, 4=ийкл, 5=мноп, 6=рсту, 7=фхцч, 8=шщъы, 9=ьэюя) |
| **← / →** | перебор кандидатов (пока слово не подтверждено) |
| **Пробел** | подтвердить слово + пробел |
| **Enter** | подтвердить слово без пробела; если слова нет — перейти в ручной ввод (multi-tap) |
| **Backspace** | стереть последнюю цифру (в multi-tap — букву) |
| **Esc** | сбросить набор (не выключает режим) |
| **Shift + буква** | следующее слово — с заглавной (буква не печатается) |
| **Sym + цифра** | цифра с заглавной (Sym+5 = `%` → первая буква заглавная) |
| остальные клавиши | работают как обычно (знаки препинания, латиница и т.д.) |

> ⚠️ **Shift+цифра не работает** для заглавной: прошивка CardKB шлёт для цифр один и тот же код с Shift и без.
> Заглавная — только через Shift+буква или Sym+цифра.

## 📖 Ручной ввод слов (multi-tap) и пополнение словаря

Набрал цифры — слова нет → окошко: `нет слова: XXX — Enter: ручной ввод`.

Жмёшь **Enter** → режим ручного ввода:
- **клик цифрой** — буква перебирается по группе (2 → а → б → в → г)
- **пауза ~0.5 с** или **другая цифра** — буква фиксируется
- **Enter** — слово печатается на экран и **сохраняется в словарь** (на диск, переживает перезапуск)

Пример: **«йога»** = `4 4` (й) · `5 5 5` (о) · `2 2 2 2` (г) · пауза · `2` (а) → Enter.
Теперь по коду `4522` слово «йога» — первый кандидат.

## 🔩 Установка

```bash
# Файлы — в workspace агента:
mkdir -p ~/.openclaw/workspace/t9
cp m5hub.py ~/.openclaw/workspace/
cp t9/* ~/.openclaw/workspace/t9/

# systemd-сервис (если ещё нет):
# /etc/systemd/system/m5hub.service
# [Service] ExecStart=/usr/bin/python3 -u m5hub.py, Environment=DISPLAY=:0
# WorkingDirectory=/home/<user>/.openclaw/workspace

sudo systemctl restart m5hub
```

## 🔨 Перегенерация словаря

```bash
# Скачать частотный список (открытая лицензия, hermitdave/FrequencyWords):
curl -sL -o /tmp/ru_50k.txt \
  https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/ru/ru_50k.txt

# Собрать базу (топ-10000 слов):
python3 t9/gen_t9_dict.py /tmp/ru_50k.txt 10000 t9/ru_t9.json
```

## 🧠 Как это работает (и грабли, на которые мы наступили)

1. **XTest-ввод русских букв — физическими keycode ЙЦУКЕН.** python-xlib кэширует карту
   клавиш при открытии `Display` и не видит смену раскладки (`keysym_to_keycode` после
   `setxkbmap ru` возвращает 0). Решение: ввод по физическим keycode (п=42, р=43, ...),
   они не зависят от кэша.
2. **X11 Cyrillic keysym'ы НЕ алфавитные** (в=0x6d7, р=0x6d2, ц=0x6c3, ч=0x6de и т.д.) —
   не пытайтесь вычислять их по unicode-коду буквы.
3. **После `setxkbmap` нужна пауза ~0.2 с** — без неё XTest-события теряются
   (сервер ещё применяет раскладку).
4. **Fn-коды CardKB = 128 + индекс клавиши** (из прошивки CardKB_Firmware.ino):
   Fn+Tab=0x8C, Fn+Backspace=0x8B, Fn+Enter=0xA3, Fn+Space=0xAF.
5. **keysym_to_keycode(keycode=0) → XTest BadValue** — всегда проверять keycode перед отправкой.
6. **LED джойстика STM32G0** гаснет при опросе осей — держать постоянно не может,
   мигает при нажатиях (используем как индикатор активности Т9).
7. **OSD-окно** — GTK3 POPUP (без рамки и фокуса), рисуется внизу по центру экрана,
   обновляется из GTK-потока через очередь.
